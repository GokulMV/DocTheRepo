## `web/package.json`

Web application package configuration for a React-based documentation tool (dth-web). Defines project metadata, build scripts, and dependencies including React 18, TanStack Query for data fetching, React Router for navigation, Recharts for visualization, and cryptographic libraries from @noble. Build tools include Vite for bundling, TypeScript for type checking, and Tailwind CSS for styling. Development scripts support local development (`dev`), production builds (`build`), testing (`test`), and type linting (`lint`).
