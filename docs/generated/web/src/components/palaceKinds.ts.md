## `__module__`

Defines metadata for 16 entity kinds (repo, service, endpoint, datastore, etc.) used throughout the documentation system. Each kind specifies a display label, plural form, color (hex), graph shape, and Lucide icon for UI rendering. Includes a fallback metadata object for unknown kinds and exports filtered arrays: `OVERVIEW_KINDS` for aggregated dashboard display and `COUNTED_KINDS` for entities requiring count tracking.
