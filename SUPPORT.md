# Getting help

- **How do I…?** Start with the [README](README.md) and the guides in [docs/](docs/). For install problems,
  see [docs/install.md](docs/install.md).
- **Found a bug?** [Open an issue](https://github.com/GokulMV/DocTheRepo/issues/new/choose) with the bug
  template. If the UI showed an error card, paste its "Details for a bug report".
- **Have an idea?** Open a feature request.
- **Security problem?** Report it privately: see [SECURITY.md](SECURITY.md).
